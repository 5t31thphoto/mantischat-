# MantisChat — M5Stack Core2

ESP-NOW chat that talks to Mantis Watches, plus a live, chaotic community
whiteboard shared by every MantisChat in range.

## Flash
Push to `main`. GitHub Actions builds the firmware and publishes the web flasher
to GitHub Pages (Settings → Pages → Source: **GitHub Actions**). The page has an
Install button (Chrome/Edge over USB) and a download link for
`mantischat-core2-merged.bin` (write at `0x0`).

## Use
- **Home:** Chat tile, Whiteboard tile, callsign (tap to edit), sound toggle.
- **Chat:** tap the message bar for the on-screen keyboard (letters, `?123`
  symbols, Shift, hold Del to repeat). Header right → **People**: tap a name to
  DM, tap Group for channel 0. Tap the title to leave a DM.
- **Whiteboard:** 6 inks, pen size, **ERASE mine** (tap one of your strokes),
  **UNDO mine**, **CLEAR mine** (tap twice). All three only ever remove *your*
  ink, from every board. Incoming chat shows as a banner — tap it to open chat.
- **Buttons under the screen:** A home · B chat / keyboard · C whiteboard.

## Specs
- `MANTISNOW.md` — chat/discovery protocol as implemented, kind registry.
- `WHITEBOARD.md` — whiteboard protocol (MantisNow kind `0x40`).
